## Договорились — не пересматривать

- Запись созвона — «Везде только весь звук»: выбор одной программы — в следующей версии (R02, R03, R07)
- Итоги только на локальной модели; облачные модели не в v1 (R35)
- Текст после встречи, не на лету: живая расшифровка — v2 по решению владельца (R25)
- Клавиша «Записать созвон» по умолчанию пустая (R12)
- Диктовка удержанием — выключена по умолчанию, короткое нажатие работает по-старому

## Не доделано

- Выбор одной программы для записи — Mac (CoreAudio process tap, 14.2+) и Windows (process loopback) — R02/R03/R07
- Автоподсказка «Zoom начал звонок — записать?» — R21
- Живая расшифровка во время звонка — R25
- Пункт «Записать созвон» в меню на одну клавишу (`src/menu.ts`) — его нет
- Живая проверка: звук компьютера на Mac (флаги Chromium `MacLoopbackAudioForScreenShare`), дубли без наушников (R10), сон посреди записи, Windows целиком
- Живая проверка исправления раскладки на Mac и удержания клавиши (нужен «Универсальный доступ»)

## Известные баги

- Второе нажатие клавиши записи, пока открыт вопрос о согласии, открывает второй вопрос — `src/main.ts` startCall
- Упавшее окно записи: итог сам не делается, `lost` не передаётся — `src/capture.ts`
- Выход из системы во время записи ждёт ответа «Остановить и сохранить?» — `src/main.ts` before-quit
- «Попробовать снова» у итога видна без скачанной модели — `src/webview/transcripts.ts`
- «42 000» и «42000» считаются разными числами — пункт итога может пропасть — `src/summary.ts` numbersOf
- `put_summary` принимает пустой текст (страница его не шлёт) — `engine/app.py`
- `TOPIC_STAMP` в `src/summaryflow.ts` дублирует `TOPIC_TIME` из `src/summary.ts`
- На Mac: подсказка раскладки у указателя, а не у курсора; после исправления Caps Lock остаётся включённым; нет тихого режима на весь экран
- Тесты, падающие на Mac и до сборки: oldfolder ×3, setup recommendedModels, storage, engine test_move_transcripts (пути Windows)
