## Что должно заработать

Над расшифровкой созвона — блок «Итог»: «Сделать итог» с выбором шаблона и «На моём языке», ход работы («часть 2 из 5 · прошло 0:43 · осталось ≈1:20», отмена), готовый итог с разделами и щёлкающимися темами (перематывают звук к месту), правка руками, пересоздание, копирование. После расшифровки своего созвона Крякл делает итог сам, если включено «Делать итог сразу» и модель скачана. Без модели — «Скачать (5,2 ГБ)». В библиотеке видны источник и отметка «Итог», поиск находит по итогу.

## Из брифа, дословно

> «После расшифровки — кнопка «Сделать итог»; настройка «Делать итог сразу» (по умолчанию включена, если модель уже скачана)»
> «Главные темы с отметкой времени — щелчок переносит в расшифровку»
> «Шаблоны: «Общий», «Планёрка», «Интервью», «Лекция/вебинар» + свой текст-инструкция»
> «Язык итога — язык встречи; переключатель «на моём языке»»
> «Время ожидания показывается»
> «Нет скачанной модели → предложить скачать (с размером), как остальные функции»
> «Итог можно поправить руками, пересоздать (с другим шаблоном) и скопировать»
> «Записи в «Записях и встречах»: название, дата, длительность, источник (Zoom, весь звук…), статус, есть ли итог; поиск по тексту»
> «Прослушать место расшифровки — существующая сжатая копия»
> «Отчёт о проблеме не включает записи, расшифровки и итоги»

## Критерии приёмки

- [ ] На странице записи блок «Итог»: «Сделать итог», шаблон (5, своя инструкция до 500 знаков), «На моём языке»; итог сохраняется через `PUT /transcripts/{id}/summary` и виден после перезагрузки
- [ ] Ход: «часть N из M», прошедшее и оставшееся время, «Отмена»; ошибка — «Не удалось сделать итог» + «Попробовать снова», расшифровка не тронута
- [ ] Темы `[mm:ss]` — ссылки: щелчок перематывает звук и прокручивает к реплике
- [ ] Правка руками сохраняется при выходе из поля (`edited`); пересоздание поверх правки спрашивает; «Копировать» кладёт текст итога
- [ ] Модель не скачана → строка с размером и «Скачать», прогресс, после — «Сделать итог» доступен
- [ ] «Делать итог сразу» (по умолчанию вкл), шаблон по умолчанию, своя инструкция, «На моём языке» — на странице «Записи и встречи»; автоитог после расшифровки созвона, только когда модель `ready`
- [ ] Библиотека: у созвона значок, источник (имя программы или «Весь звук»), отметка «Итог»; заметка «Потеряно кусков записи: N» на странице записи при `lost>0`
- [ ] В журналы не пишется текст итога; `report.ts` не берёт записи; новые фразы en/uk/ru; `npm run typecheck`, `npm test`, `npm run build` зелёные
